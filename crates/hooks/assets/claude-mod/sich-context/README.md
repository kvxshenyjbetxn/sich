# sich-context

Claude Code mod bundled with Sich. It only exports data: no pane, command or UI.

For each session it writes the context-window breakdown and subagent run usage to
`<sich config>/claude-ctx/<sessionId>.mod.json`, where Sich reads it. It does nothing unless
`SICH_TERM_ID` is set, so Claude sessions outside Sich are not affected.

Sich installs this folder at `<sich config>/claude-mod/sich-context/` and lists it in
`env.CLAUDE_CODE_PLUGIN_DIRS` of Claude's `settings.json`. Turning off "Claude context (mod)" in
the Sich settings removes both again.

## Develop

```sh
claude plugin validate .
npx tsc -p .
```

`.claude-plugin/types/` is generated by the engine and git-ignored.
